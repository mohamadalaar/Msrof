# مصروف بيتنا

تطبيق عربي لتسجيل المدخول والمصروف بعدة عملات وحساب التقرير الشهري بالتركي والدولار.

## النشر المجاني على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub باسم `masroof-baytna` واجعله `Public` لاستخدام Pages على الخطة المجانية.
2. فك ضغط الملف، وارفع الملفات والمجلدات الموجودة بداخله إلى جذر المستودع عبر **Add file → Upload files**. ارفع `index.html` و`app.js` و`core.js` و`style.css` و`icon.svg` ومجلد `fonts`، وليس ملف ZIP نفسه. لا تضع هذه الملفات داخل مجلد إضافي.
3. اضغط **Commit changes** لحفظ الملفات على فرع `main`.
4. افتح **Settings → Pages**.
5. ضمن **Build and deployment** اختر **Source: Deploy from a branch**.
6. اختر **Branch: main** والمجلد **/(root)**، ثم اضغط **Save**.
7. انتظر اكتمال النشر. رابط الموقع يظهر في صفحة **Pages** ويكون عادةً:
   `https://YOUR-USERNAME.github.io/masroof-baytna/`

التطبيق ثابت، ولا يحتاج سيرفراً أو تثبيت مكتبات أو أمر بناء. إذا لم يظهر خيار Pages، تأكد من صلاحيتك لإدارة المستودع وأنه Public على الخطة المجانية.

## بدء الاستخدام

افتح «أسعار الصرف»، وحدد الأسعار مقابل الليرة التركية، ثم سجّل الدخل والمصروف. سعر الليرة السورية يُدخل لكل ألف ليرة سورية. اضغط «احسب هذا الشهر» لحفظ تقرير الشهر المختار.

## نقل بياناتك من الرابط السابق

بيانات التطبيق محفوظة محلياً في نفس المتصفح، وكل رابط له تخزين مستقل. نزّل نسخة JSON من «بياناتي والنسخ الاحتياطي» على الرابط السابق، ثم استعدها من نفس القائمة على رابط GitHub Pages. لا ترفع ملفات النسخ الاحتياطية أو بياناتك الشخصية إلى المستودع.

لا توجد مزامنة تلقائية بين الأجهزة. يمكنك نقل البيانات عبر النسخ الاحتياطية.

## تعديل التطبيق

- `index.html`: الهيكل والواجهات العربية.
- `style.css`: التصميم المتجاوب والخطوط.
- `app.js`: الإدخال والحفظ والتقارير والتنزيل.
- `core.js`: الحسابات والتحقق والعملات وحدود الأشهر.
- `fonts/`: الخطوط المحلية ورخصتها.

أي تعديل تحفظه على `main` سيظهر بعد انتهاء إعادة نشر Pages.

## فحوص اختيارية للمطور
